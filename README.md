# Hosts File Manager

[English Version](./README.en.md)

> **Linguagem / Stack:** `C# (.NET 4.8)` | **Autor:** `piercer`

## O que faz

Editor visual seguro para C:\Windows\System32\drivers\etc\hosts com backup automático.

## Como executar

```bash
build.bat  # ou execute piercer_hosts-file-manager.exe
```
